#  Real-Time MERN Chat Application

A full-stack real-time chat application where users can register, 
login and chat with each other instantly without page refresh.

##  Live Demo
[Click Here to Open App](https://real-time-mern-chat-app-client.vercel.app)

##  Features
-  User Registration & Login with JWT Authentication
-  Real-time messaging using Socket.io
-  Online/Offline user status indicator
-  Responsive design for mobile and desktop
-  Secure password hashing with bcrypt
-  Instant message delivery without page reload

##  Tech Stack

### Frontend
- React.js
- React Context API (for global auth state)
- Socket.io-client
- Axios
- React Router DOM
- CSS3

### Backend
- Node.js
- Express.js
- Socket.io
- MongoDB + Mongoose
- JWT (JSON Web Tokens)
- bcryptjs
